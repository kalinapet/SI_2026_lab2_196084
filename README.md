## 1. Код
Во `src/main/java` ја ставив класата **SI2026Lab2Main.java**. Во неа се наоѓаат класите `Book` и `Library`. Две функции беа најважни за оваа лабораториска:
- `searchBookByTitle` – пребарува книги по наслов и враќа листа од книги што не се изнајмени, или `null` ако нема такви.
- `borrowBook` – наоѓа книга по наслов и автор и ја означува како изнајмена, или фрла исклучок ако има проблем.

---

## 2. Control Flow Graph (CFG)
За секоја функција нацртав дијаграм што покажува како тече извршувањето.

### searchBookByTitle
- Почеток
- Проверка дали насловот е празен → ако е, фрла исклучок
- Циклус низ сите книги
- Проверка дали насловот се совпаѓа и книгата не е изнајмена
- Ако условот е точен → додавање во резултати
- По циклусот → ако нема резултати враќа `null`, инаку враќа листа

### borrowBook
- Почеток
- Проверка дали наслов или автор е празен → ако е, фрла исклучок
- Циклус низ сите книги
- Проверка дали наслов и автор се совпаѓаат
- Ако се совпаѓаат → проверка дали книгата е веќе изнајмена
- Ако не е → ја изнајмува
- Ако е → фрла исклучок
- Ако не се најде книга → фрла исклучок

## 3. Цикломатска комплексност
Формулата е:  **M = E - N + 2P**

- **searchBookByTitle**  
  - Има услов за празен наслов  
  - Има циклус со услов  
  - Има проверка дали резултатите се празни  
  → M = 4

- **borrowBook**  
  - Има услов со OR (title.isEmpty || author.isEmpty)  
  - Има циклус со услов  
  - Има вложен if за borrowed  
  - Има повеќе места каде се фрла исклучок  
  → M = 5

++ Бројот покажува колку различни патеки може да има низ кодот. Колку е поголем бројот, толку е покомплексна функцијата.

## 4. Every Statement тестови
Функција: `searchBookByTitle`  
Тестови:
- Тест1: Пронајдена книга → покрива циклус и додавање во резултати.  
- Тест2: Непостоечка книга → покрива враќање `null`.  
- Тест3: Празен наслов → покрива фрлање исклучок.  

Минимално: **3 тест случаи**.

## 5. Every Branch тестови
Функција: `borrowBook`  
Тестови:
- Тест1: Празен наслов → IllegalArgumentException.  
- Тест2: Непостоечка книга → RuntimeException.  
- Тест3: Успешно изнајмување → враќа успешно.  
- Тест4: Веќе изнајмена книга → RuntimeException.  

Минимално: **4 тест случаи**.

## 6. Multiple Condition тестови
### searchBookByTitle
Услов: `book.getTitle().equalsIgnoreCase(title) && !book.isBorrowed()`  
- Тест1: True && True → враќа книга.  
- Тест2: True && False → враќа null.  
- Тест3: False && * → враќа null.  

Минимално: **3 тест случаи**.

### borrowBook
Услов: `title.isEmpty() || author.isEmpty()`  
- Тест1: True || * → IllegalArgumentException.  
- Тест2: * || True → IllegalArgumentException.  
- Тест3: False || False → успешно изнајмување.  

Минимално: **3 тест случаи**.
